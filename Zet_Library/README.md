# Zet Library

Empty external library scaffold for a new Zet deployment.

Configure `BaseLibraryPath` in Zet's `config.toml` to point to this directory. Zet creates character, asset, pipeline, story, and auxiliary-resource content beneath the existing folders as it is used.

The files under `Characters/_Shared`, `AuxiliaryResources/_Shared`, and `Stories` are required shared templates and should be retained.
