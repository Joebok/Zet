# Scenes and Stories

## Objective

Build a framework to manage the construction of "scenes" under an umbrella of a "story"

A **scene** is
* narrative description of the scene (markdown file)
* an associated image

A **story** is
* a markdown file telling/describing the story.
* links to one or more scenes

## File Storage

I will be editing story and scene files from various devices. (stories define a folder structure, scenes are markdown files) I keep track of them with a github repository. I would like Zet to be able to do fetch/pull/commit operations on that story repo so I can edit the items from the Zet dashboard as well.

Can this be done? The entire Zet project is a github repo, can you nest one repo inside of another without screwing anything up?

A story will be a folder and a markdown file.
