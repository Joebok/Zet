# Environmental universe style
Status: accepted
Date: 2026-10-30

Extend ADR 0012 with a separate environmental style. Missing selections resolve canonical, including existing Narrative targets. Explicit target inheritance uses the value inherit. New backdrops select environmental. Character batches freeze their style before compiling any view, in a batch-owned Universe_Style.json snapshot. Minor Characters retains style_mode and a separate universe_style_variant and uses shared reconstruction provenance. Overview reuse compares variant and frozen style hash. Image-driven Assembly retains its existing rendering instructions.

Validation is recorded in the implementation plan; live image quality is unverified.
