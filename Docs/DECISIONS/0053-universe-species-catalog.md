# 0053 - Universe Species catalog

Status: Accepted

The Character Wizard and Manual Setup need to offer species that Body Reference
can resolve. Store stable Species IDs in newly authored Character.md files and
use the same catalog service for authoring and compilation. Ship starter
definitions with Zet and let each universe save its own catalog. An edited
universe owns its complete catalog, so later seed changes apply automatically
only to universes using the bundled definitions.

Apply catalog rules when compiling new prompts. Keep previously prepared
requests and completed images tied to their captured production inputs.
See the [data model](../DATA_MODEL.md#species-catalog).
