# Retired Scene Builder

Scene Builder, old scene authoring, scene interviews, local scene batches and their
render/review pipeline are retired. The dashboard Stories workspace mounts
[Narrative](NARRATIVE.md); `/narrative` redirects there. Legacy authoring/execution
APIs return retirement responses and do not dispatch work.

Dedicated 3D models/services/browser code, compilers and historical integration
fragments are preserved outside runtime in the [offline archive](../../Archive/scene-builder/README.md).
The archive owns restoration instructions, original units/grouping rules and dependency
metadata. Existing V4 JSON, Markdown, images, saved layouts and other stories remain
preserved in their source libraries. No geometry is converted into Narrative state.

The eight authored First Day and twenty Phlan Adventures scenes became reviewed
Narrative stubs: backdrop, subject subscene(s), assembly direction, current costume
bindings and required imported references. All 28 final images are independent
catalog assets displayed below Save scene / Delete scene. The empty Collision draft
was excluded and copied to the migration archive. Missing references remain issues.

[Migrations and Candidates](NARRATIVE.md) own the active behavior; [ADR 0005](../DECISIONS/0005-narrative-dashboard-and-legacy-scene-retirement.md)
records the boundary. There is no maintained retired-pipeline/geometry scenario.
Do not run archived tools against the creative library as validation.
