# Qwen Image 2.1 Prompts

Recommended Prompt Order

1. The Style Opener (First Words): Explicitly name the format and medium as the very first phrase. This anchors the global aesthetic before you introduce any character details.

2. Type of Piece (The Format)
State what you are making right away (e.g., an editorial portrait, a character design sheet, a full-body fantasy illustration).

3. Subject & Core Identity
Name the character type, age (as a number like "17" with clear trait bounds), and primary species or role.

4. Physical Traits & Face
Describe hair, eyes, facial features, and skin tone (use explicit negative constraints like "not tanned" if needed).

5. Clothing & Wardrobe
Detail the outfit, primary garments, and key gear. Keep small accessories minimal if generating multiple angles.

6. Setting & Background
Define the environment, backdrop, or neutral studio space where the character stands.

7. Lighting & Finish
Specify the lighting style (e.g., soft rim light, dramatic studio light) and the artistic medium or finish (e.g., digital paint, live-action photograph).

8. The Style Closer (Last Words): Finish the prompt by describing the physical rendering materials, line quality, surface textures, or specific artistic finishes.
