# Anatomical Requirements

Render anatomically correct characters.

- Every visible hand has exactly five fingers in the correct anatomical arrangement.
- Hands, wrists, elbows, shoulders, legs, feet, necks, and torsos are naturally connected.
- No extra limbs, missing limbs, fused limbs, duplicated body parts, or disconnected anatomy.
- Fingers have natural proportions and believable poses.
- Character interactions do not cause anatomy to intersect or merge.

# Avoid

- Inconsistent character identity.
- Wrong costume.
- Modern objects.
- Unreadable faces.
- Merged characters.
- Cropped characters.
- Anatomical distortions.

# High-Risk Elements

Pay particular attention to:

- Hands making gestures.
- Characters sitting with crossed legs.
- Characters touching or closely facing each other.
- Objects held in the hands.
- Long ears remaining fully attached and correctly shaped.
- Hair remaining consistent with the reference.
