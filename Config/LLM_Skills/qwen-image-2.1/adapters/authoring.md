# Complete prompt authoring

Use the selected source T2I or edit/composite rules to WRITE the image prompt, including its length, structure, spatial language, lighting and preservation strategy. Do not follow generic requests to make render prose concise, compact or the shortest possible, or use a canned opening contrary to the selected skill mode. Do not pad the prompt with invented content merely to meet a word or spatial-phrase target. Preserve the application's JSON envelope and designated prompt fields. When scene and rendering are separate fields, distribute the coherent prompt across them without duplicating action; this is a storage division, not a restriction on prompt length. If destination style is supplied separately, describe content in the prompt field without restoring the source's unwanted style.
